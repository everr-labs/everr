title: Installation

---

The Everr CLI is all you need for observability tasks. With a single command, you can:
- Start a local collector and UI to explore local telemetry
- Use specialized AI skills
- Query local and remote telemetry with SQL syntax, or let your agent do it
- Preview and publish your dashboards, alerts, and other [Observability as code](/docs/concepts/observability-as-code) resources.


## Install the CLI

Run this in your terminal:

```sh
curl -fsSL https://everr.dev/install.sh | sh
```

Follow the installer's PATH instructions, then check that the CLI is available:

```sh
everr --version
```

See the [CLI reference](/docs/reference/cli) for supported platforms and install options. Use `everr upgrade` to update the CLI and its bundled local UI.

## Connect your coding agent

Everr skills guide your agent through instrumentation, telemetry investigations, and creating dashboards, alerts, and runbooks. Install them from your project root:

```sh
everr skills install --all --project
```

Use `--global` instead of `--project` if you want the skills available across projects. See [Skills](/docs/reference/skills) for supported agents and update commands.

Prefer to configure OpenTelemetry yourself? Continue with the manual path in [Instrument your app](/docs/learn/instrument-your-app).

## Connect to an installation

From your repository, run `everr cloud login` to connect to [Everr Cloud](https://app.everr.dev/). For a self-hosted installation, supply its app URL:

```sh
everr cloud login --url https://observability.acme.com
```

Approve the login in your browser and choose your organization. The CLI saves one session in your user configuration directory. A later successful login replaces that session.

Run `everr cloud status` to check the current installation, account, organization, and ingestion endpoint. To switch installations, run `everr cloud login --url <app-url>` again. See [Authentication](/docs/reference/cli#authentication-and-remote-queries) for session storage and login options.

Local telemetry and the local UI work without a remote login.
