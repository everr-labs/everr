This is step 1 of getting started with Everr: install the CLI and finish first-time setup. By the end you'll have `everr` on your PATH, agent skills installed, and be ready for step 2: instrumenting your app locally.

## Install the CLI

Run the installer from a terminal:

```sh
curl -fsSL https://everr.dev/install.sh | sh
```

Expected output: the installer adds the `everr` CLI to your PATH and, if your terminal is interactive, runs `everr setup` automatically.

For the full list of supported platforms and every install flag, see the [CLI reference](/docs/reference/cli).

## Finish setup

If setup didn't run automatically, or was interrupted, run it yourself:

```sh
everr setup
```

Setup installs Everr's skills for your coding agent and shows how to start the local collector. Local onboarding works without signing in or creating an ingest key.

When you want Cloud telemetry or CI visibility later, run `everr cloud login`.

## Start local telemetry

Run `everr local start` to start the local collector and open its browser UI. Keep that terminal session running while you work locally. For an agent or a terminal without a browser, use `everr local start --no-open`.

## Install skills for your Agent

Skills teach your Agent when and how to use Everr. Install them globally so every project picks them up:

```sh
everr skills install --all --global
```
