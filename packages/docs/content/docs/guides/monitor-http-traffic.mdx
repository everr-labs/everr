---
title: Monitor HTTP traffic
description: A dashboard with request rate, p99 latency, and 5xx error rate panels from your traces.
---

One `Dashboard` file gives you the three golden HTTP signals — request rate, latency, error rate:

```yaml
kind: Dashboard
metadata:
  name: http-traffic
  project: default
spec:
  display:
    name: HTTP traffic
    description: Request rate, latency, and errors for one service.
  duration: 1h
  refreshInterval: 30s
  panels:
    req-rate:
      kind: Panel
      spec:
        display: { name: Request rate (req/s) }
        plugin:
          kind: TimeSeriesChart
          spec: { unit: "/s", showLegend: false }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT toStartOfInterval(Timestamp, INTERVAL {step:UInt32} SECOND) AS ts,
                           count() / {step:UInt32} AS req_per_sec
                    FROM traces
                    WHERE Timestamp >= {from:String} AND Timestamp <= {to:String}
                      AND ServiceName = 'my-app'
                      AND SpanKind = 'Server'
                    GROUP BY ts
                    ORDER BY ts
    latency:
      kind: Panel
      spec:
        display: { name: p99 latency (ms) }
        plugin:
          kind: TimeSeriesChart
          spec: { unit: " ms", showLegend: false }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT toStartOfInterval(Timestamp, INTERVAL {step:UInt32} SECOND) AS ts,
                           quantile(0.99)(Duration) / 1e6 AS p99_ms
                    FROM traces
                    WHERE Timestamp >= {from:String} AND Timestamp <= {to:String}
                      AND ServiceName = 'my-app'
                      AND SpanKind = 'Server'
                    GROUP BY ts
                    ORDER BY ts
    error-rate:
      kind: Panel
      spec:
        display: { name: Error rate (5xx) }
        plugin:
          kind: TimeSeriesChart
          spec: { unit: "%", showLegend: false }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT toStartOfInterval(Timestamp, INTERVAL {step:UInt32} SECOND) AS ts,
                           countIf(toInt32OrZero(SpanAttributes['http.response.status_code']) >= 500)
                             / count() * 100 AS error_pct
                    FROM traces
                    WHERE Timestamp >= {from:String} AND Timestamp <= {to:String}
                      AND ServiceName = 'my-app'
                      AND SpanKind = 'Server'
                    GROUP BY ts
                    ORDER BY ts
  layouts:
    - kind: Grid
      spec:
        items:
          - { x: 0,  y: 0, width: 12, height: 8, content: { $ref: "#/spec/panels/req-rate" } }
          - { x: 12, y: 0, width: 12, height: 8, content: { $ref: "#/spec/panels/latency" } }
          - { x: 0,  y: 8, width: 24, height: 8, content: { $ref: "#/spec/panels/error-rate" } }
```

Apply it:

```sh
everr apply
```

## If you want one line per service

Drop the `ServiceName` filter and add `ServiceName` to `SELECT` and `GROUP BY`. A remaining non-numeric string column pivots the value column into one line per service — see [Visualizations](/docs/reference/visualizations) for the full shaping rules.

```sql
SELECT toStartOfInterval(Timestamp, INTERVAL {step:UInt32} SECOND) AS ts,
       ServiceName,
       count() / {step:UInt32} AS req_per_sec
FROM traces
WHERE Timestamp >= {from:String} AND Timestamp <= {to:String}
  AND SpanKind = 'Server'
GROUP BY ts, ServiceName
ORDER BY ts
```

## If you want a top-routes table

Swap the panel plugin for a `Table` and aggregate over the window instead of per bucket — see [Visualizations](/docs/reference/visualizations).

```yaml
    top-routes:
      kind: Panel
      spec:
        display: { name: Top routes by p95 latency }
        plugin:
          kind: Table
          spec: { stickyHeader: true }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT SpanAttributes['http.route'] AS route,
                           count() AS requests,
                           round(quantile(0.95)(Duration) / 1e6, 1) AS p95_ms
                    FROM traces
                    WHERE Timestamp >= {from:String} AND Timestamp <= {to:String}
                      AND ServiceName = 'my-app'
                      AND SpanKind = 'Server'
                      AND SpanAttributes['http.route'] != ''
                    GROUP BY route
                    ORDER BY p95_ms DESC
                    LIMIT 15
```
