---
title: Track infra health with a runbook
description: A multi-page runbook with a freshness stat, shared panels, and per-topic triage pages.
---

A health runbook answers "is it working right now?" the moment it opens — put a freshness stat first. The runbook — `infra-health.runbook.yaml`:

```yaml
kind: Runbook
metadata:
  name: infra-health
spec:
  display:
    name: Infrastructure health
  duration: 1h
  refreshInterval: 30s
  panels:
    freshness:
      kind: Panel
      spec:
        display: { name: Metrics lag (seconds since last datapoint) }
        plugin:
          kind: StatChart
          spec:
            calculation: last
            unit: "s"
            decimals: 0
            colorMode: background
            thresholds:
              mode: absolute
              defaultColor: "#22c55e"
              steps:
                - { value: 120, color: "#f59e0b" }
                - { value: 300, color: "#ef4444" }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT dateDiff('second', max(TimeUnix), now()) AS lag_seconds
                    FROM metrics_gauge
                    WHERE TimeUnix >= {from:String} AND TimeUnix <= {to:String}
                      AND MetricName = 'k8s.node.cpu.usage'
    ingest-rate:
      kind: Panel
      spec:
        display: { name: Datapoints ingested }
        plugin:
          kind: TimeSeriesChart
          spec: { unit: " dp" }
        queries:
          - kind: ClickHouseSQL
            spec:
              plugin:
                kind: ClickHouseSQL
                spec:
                  query: |
                    SELECT toStartOfInterval(TimeUnix, INTERVAL {step:UInt32} SECOND) AS ts,
                           count() AS datapoints
                    FROM metrics_gauge
                    WHERE TimeUnix >= {from:String} AND TimeUnix <= {to:String}
                      AND (MetricName LIKE 'k8s.node.%' OR MetricName LIKE 'k8s.pod.%')
                    GROUP BY ts
                    ORDER BY ts
  markdown:
    file: ./infra-health.runbook.md
  pages:
    - name: collector
      display: { name: Collector not reporting }
      markdown: { file: ./infra-health/collector.runbook.md }
```

The index page embeds that shared panel — `infra-health.runbook.md`:

````md
## 1. Is data fresh?

Green (< 120s) means metrics are arriving; amber or red means they've stopped — go to [Collector not reporting](collector).

```panel
ref: freshness
height: 180
```

## 2. Is ingestion steady?

A flat, continuous line is healthy; a drop toward zero means the collector is crashing or losing its export path.

```panel
ref: ingest-rate
height: 200
```
````

The freshness stat reads correctly on a now-anchored window (the seeded `duration` default); panning the time picker to a past window caps `max(TimeUnix)` and skews the number.

## Why shared panels

Declare a panel once under `spec.panels`, then `ref:` it from any page in the tree — the `collector` child page can embed the same `ref: freshness` again. Edit the query or thresholds once and it propagates everywhere it's embedded.

## Structuring the page tree

The index page is `spec.markdown`; nest triage topics under `spec.pages`. Each `name` is the URL slug, joined onto the parent's path — the child above lives at `/runbooks/default/infra-health/collector`.

```yaml
spec:
  markdown:
    file: ./infra-health.runbook.md   # index page; required
  pages:
    - name: collector                 # slug; unique among siblings
      display: { name: Collector not reporting }
      markdown: { file: ./infra-health/collector.runbook.md }
      pages:                          # nest arbitrarily deep
        - name: exporters
          markdown: { file: ./infra-health/exporters.runbook.md }
```

Link between pages by relative markdown path or page path (`[Collector not reporting](collector)`); absolute and `http(s):` URLs are left untouched.

## Seeding time range and refresh

A triage runbook wants a short window and auto-refresh: `duration: 1h` frames "right now" and `refreshInterval: 30s` repolls without a manual reload.
