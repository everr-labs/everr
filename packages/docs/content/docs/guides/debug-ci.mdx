---
title: Debug Your CI
description: Use Everr to investigate CI failures and regressions.
---

Everr stores GitHub Actions runs, jobs, steps, and step logs as telemetry,
so your coding assistant investigates CI the same way it investigates any
other runtime behavior.

Install the bundled Everr skills (see [Skills](/docs/reference/skills)) and
ask the assistant about the failing branch, commit, pull request, or run.
It uses the `everr-use-telemetry` skill to query CI data with
`everr cloud query`. You can also browse runs in the Everr web app.
