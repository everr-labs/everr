---
title: Connect a repository
description: Connect the Everr GitHub App and import recent workflow history from Everr Cloud.
---

Connect repositories from the **GitHub** page in Everr Cloud. An organization admin or owner must manage the installation and import workflow history.

## Connect the GitHub App

1. Open [Everr Cloud](https://app.everr.dev/) and select the organization that should receive the repository's CI data.
2. Open the user menu and select **GitHub** under **Organization settings**.
3. Select **Install GitHub App**, or **Update installation** if GitHub is already connected.
4. In GitHub, grant the Everr App access to the repositories you want to observe.
5. Return to Everr's GitHub page and check that it shows **GitHub connected** and lists your repositories.

The GitHub App sends future workflow events to the selected Everr organization. Your repository does not need local Everr configuration or changes to its workflows.

## Import recent runs

Under **Import workflow history**, select up to three repositories and choose **Import selected**. You can return and import more repositories later.

The page shows import progress. Once it reports **Import complete**, select **View runs** to inspect the imported history. Workflow data appears gradually as queued runs, jobs, steps, and logs are processed.

## Verify the setup

Check recent runs in Everr Cloud, or use the CLI:

```sh
everr cloud login
everr ci runs --repo owner/repo --limit 5
```

Replace `owner/repo` with your GitHub repository. If you are already signed in to the intended organization, you can skip the login command.

For a new workflow execution, run this from the repository checkout to watch the current commit:

```sh
everr ci watch
```

If no runs appear yet, wait for ingestion to catch up or trigger a new GitHub Actions run.

Next, add [Resource Monitoring](/docs/guides/resource-monitoring) to any jobs where you want per-job CPU, memory, network, and disk metrics.
