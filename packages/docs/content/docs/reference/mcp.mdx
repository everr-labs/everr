## Overview

Everr exposes a read-only [MCP](https://modelcontextprotocol.io) server so AI clients (Claude, Cursor, the MCP Inspector, …) can query your organization's telemetry directly. It is intended for cases the CLI and skills don't cover — ad-hoc, model-driven exploration.

## Endpoint

|           |                             |
| --------- | --------------------------- |
| URL       | `https://app.everr.dev/mcp` |
| Transport | Streamable HTTP             |
| Auth      | OAuth 2.1                   |

## Connecting a client

**Claude Code**

```shell
claude mcp add --transport http everr https://app.everr.dev/mcp
```

Then run `/mcp` in a session to complete the browser login.

**Claude Desktop** — Settings → Connectors → Add custom connector → paste `https://app.everr.dev/mcp`.

**Codex CLI**

```shell
codex mcp add everr --url https://app.everr.dev/mcp
codex mcp login everr
```

The login command opens the browser OAuth flow.

**Codex Desktop** — Settings → Integrations & MCP → MCPs → Add a new server → paste `https://app.everr.dev/mcp`.

**OpenCode**

```shell
opencode mcp add everr --url https://app.everr.dev/mcp
opencode mcp auth everr
```

The auth command opens the browser OAuth flow.
