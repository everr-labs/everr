---
title: Browser telemetry
description: Send OpenTelemetry traces, logs, and metrics to Everr straight from web pages with a public, origin-bound API key.
---

Everr accepts OTLP directly from browsers. Because anything embedded in a web
page is visible to every visitor, browser ingestion uses a **public API key**:
a key that is safe to ship in page source because it only works from the
origins you allowlist, and it cannot do anything except send telemetry.

## Public keys

A public key differs from a regular (secret) key in three ways:

- It only authenticates requests coming from one of its **allowed origins**
  (the browser's `Origin` header must match exactly).
- It is **browser-only**: requests without an `Origin` header are rejected,
  so it cannot be used from servers or CLI tools.
- It is locked to the **Send telemetry** capability. It can never manage
  resources with `everr apply` or act on any other API.

Secret keys are the mirror image: they keep working for servers and
collectors, and they are always rejected for requests that carry a browser
`Origin` header. A leaked secret key cannot be replayed from a website.

## Mint a public key

In the Everr dashboard, open the user menu (top-left) and click **API
keys**, then **New key**.

1. Turn on **Public browser key**.
2. Add every origin your app is served from, one per line, for example
   `https://app.example.com` or `http://localhost:5173`. An origin is
   scheme://host with an optional port: no paths.
3. Create the key and copy it. Origins cannot be edited later; to change
   them, mint a new key and rotate the value in your frontend config.

## Configure the OTel web SDK

Point any OpenTelemetry web SDK at Everr with the key as a bearer token:

```ts
import { OTLPTraceExporter } from "@opentelemetry/exporter-trace-otlp-http";
import {
  BatchSpanProcessor,
  WebTracerProvider,
} from "@opentelemetry/sdk-trace-web";

const exporter = new OTLPTraceExporter({
  url: "https://ingest.everr.dev/v1/traces",
  headers: { Authorization: "Bearer <your-public-key>" },
});

const provider = new WebTracerProvider({
  spanProcessors: [new BatchSpanProcessor(exporter)],
});
provider.register();
```

Logs and metrics work the same way with the matching exporters
(`/v1/logs`, `/v1/metrics`).

Requests from an origin that is not on the key's allowlist return **401
Unauthorized**, and the SDK drops the batch.

## Local development

The local Everr collector (started by the CLI and the desktop app) accepts
browser OTLP on `http://127.0.0.1:54318` with no key and no origin setup.
Public keys only matter for sending browser telemetry to Everr cloud.
