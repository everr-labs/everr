---
title: Notifications
description: Send firing and resolved alerts to Telegram and Slack, with one notification per evaluation.
---

When an alert evaluates, Everr sends one notification summarizing all instance changes. Channels are configured in the app, not as code, and apply to every rule in the org. Currently Telegram and Slack are supported.

## Open notification settings

In Everr, go to **Alerts** and click **Notification settings** (top-right of the Alerts list). Each channel has an enable toggle and its recipients. An enabled channel must have at least one recipient before you can save.

## Send to Telegram

Enable **Telegram** and add one or more entries. Each entry pairs a **bot token** (like `123456789:ABC...`) with a **chat ID** (e.g. `-1001234567890` for a group) and an optional **name**. To create a bot and get its token, follow Telegram's [BotFather guide](https://core.telegram.org/bots/features#botfather).

Entries are immutable: you add or delete them, you do not edit them in place. The bot token is **write-only** — after saving, Everr never shows it again. To change a token, delete the entry and add a new one. The chat ID remains visible.

To find a chat ID:

- Add your bot to the chat and read the ID from the Telegram Bot API [`getUpdates`](https://core.telegram.org/bots/api#getupdates) response, or
- Open the channel or group in the [Telegram web app](https://web.telegram.org) and copy the number from the URL, for channels and supergroups it's the `-100…` value, which is the chat ID.

## Send to Slack

Enable **Slack** and add one or more **Incoming Webhook** URLs. In Slack, open the [Slack app dashboard](https://api.slack.com/apps), select the app that should post alerts, then go to **Incoming Webhooks**. Turn on **Activate Incoming Webhooks** if needed, click **Add New Webhook to Workspace**, choose the channel, and authorize the app. Slack sends you back to the app settings page, where the URL appears under **Webhook URLs for Your Workspace**. Copy the `https://hooks.slack.com/services/...` URL and paste it the Everr alerts notification settings.

Each webhook posts to one Slack channel. Give each webhook an optional name so you can remember which channel it targets.

Webhook URLs are write-only: after saving, Everr never shows the URL again — to change one, delete it and add a new one. Each enabled webhook receives every alert notification for the organization.

## Silence during maintenance

To stop notifications for a known issue or maintenance window without deleting the rule, silence it from the alert's detail page. Use the **Silence** action on a firing instance and set a time window. The rule keeps evaluating; silenced instances are filtered out of notifications. If all instances are silenced, no notification is sent.
