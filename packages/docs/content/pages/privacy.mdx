This page explains what the everr.dev website (the marketing site, the documentation, and the devlog) collects when you visit it. It does not cover the telemetry you send to Everr Cloud at app.everr.dev; that data belongs to your organization and is handled under the terms you accept when you sign up.

## What we collect on everr.dev

We measure how the site is used so we can improve the documentation and fix problems. We use two tools, and neither sets a cookie:

- **Everr browser telemetry.** We run Everr on our own site. It records page views, clicks on links and buttons, page load performance (Web Vitals), network request timings, and JavaScript errors, and sends them to Everr as OpenTelemetry log records. It keeps its identifiers in memory only, so they end when you close or reload the page.
- **PostHog product analytics.** PostHog runs in cookieless mode. It records page views and similar usage events without storing an identifier in your browser.

Like any web server, the servers that host everr.dev receive your IP address and browser user agent with each request in order to deliver the page.

## What we do not do

We do not run advertising trackers or use the site analytics to build profiles of individual visitors. The install script at `https://everr.dev/install.sh` downloads the CLI and does not send anything about your machine beyond the download requests themselves.

## Third-party links

The site links to services we do not run, such as GitHub, Discord, X, LinkedIn, and Google Calendar for booking calls. Those services apply their own privacy policies.
