Pages re-render less as you work in them, so lists, filters and charts respond faster.

- Times shown as "5m ago" and silence countdowns such as "ends in 4m" now keep up with the clock, instead of updating only when something else on the page changes.
- An API key that expires while its page is open now shows as expired.
