Surface app updates and gate installs behind user action: a sidebar update button, a green status badge on the tray icon, and a "Restart to update" tray menu item now appear when an update is staged, and the update installs only when the user triggers it. A vanished staged artifact (e.g. removed by OS temp cleanup) now self-heals by re-downloading instead of getting stuck.
